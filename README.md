Junior web developer and UI/UX designer based in Cambodia. I build full-stack products — mostly for small businesses back home — and I tend to pick projects partly for what they'll force me to learn next.

### 🔭 What I'm building

- **Freelance products for small businesses.** [KhmerFlow](#-featured-projects) is a full SaaS POS and inventory system for Cambodian shops. Stripe doesn't serve local merchants well, so I'm building KHQR/ABA PayWay support directly instead.
- **A finance app with real polish.** [Obsidian](#-featured-projects) started as a working expense tracker; I'm now pushing the UI toward something that feels premium — glassmorphism, gradient accents, motion.
- **Whatever teaches me something new.** TraceGeo meant learning Laravel and wiring up an AI model for image analysis. RetroLens Pro meant learning computer vision from zero. I pick projects partly for the gap they fill in what I know.
- **A freelance track record.** Taking on local Cambodian clients and building a profile on Upwork alongside them.

### 📌 Featured projects

**[KhmerFlow](https://github.com/neagsom229-lang/KhmerFlow)** — full-stack SaaS POS and inventory platform for Cambodian small businesses. React/Vite front end, Express API on Render, PostgreSQL on Neon. Includes a KHQR/ABA PayWay payment flow, built as a local-market alternative to Stripe. *(An earlier, fully separate version also exists rebuilt in Django — same product, different stack, mostly to compare the two.)*

**[Obsidian](https://github.com/neagsom229-lang/Tracker_Pro)** — expense tracker SaaS with a working Stripe billing tier, budgets, recurring transactions, and CSV export. React, Tailwind CSS, Zustand, Supabase. Mid-redesign into a glassmorphic bento-grid dashboard with Framer Motion and Recharts.

**[TraceGeo](https://github.com/neagsom229-lang/TraceGeo)** — Laravel 11 app that identifies a landmark from a photo using the Gemini API, geocodes it with Nominatim, and shows the result on a 3D-globe interface.

**[RetroLens Pro](https://github.com/neagsom229-lang/RetroLens-Pro)** — Python, OpenCV, and MediaPipe camera app: real-time hand tracking drives gesture-controlled visual effects, including a Fire Mode.

**[SNPro](https://github.com/neagsom229-lang/SNPro)** — Flask-based professional toolkit with a dark/light theme system built on CSS custom properties.

**[Portfolio](https://github.com/neagsom229-lang/Chh_Sn_Portfolio)** — personal site, React + Vite, currently being rebuilt section by section (Hero, Work Gallery, About, Awards, Contact) to match a reference design.

Also somewhere in the archive: a Cambodian bookstore front end, a sellable Bootstrap business-site template, a Microsoft Access inventory system, and a tkinter bubble-sort visualizer — early reps from learning the fundamentals.

### 🎨 Design language

Rich over minimal — dark themes, gradient accents, glassmorphism, and motion that earns its place. If a dashboard I built looks quiet, it's probably still mid-redesign.

### 📓 How I work

- If I don't know a stack yet, that's usually part of why I picked the project — Laravel for TraceGeo, computer vision for RetroLens Pro, a from-scratch Django rebuild of KhmerFlow just to compare it against the Node version.
- "Done" is a soft word here. Most of these projects are past their first working version and still getting redesigned.
- I build for real use, not just a demo — KhmerFlow and Obsidian both need to hold up for an actual small business, not just look good in a screenshot.
